# Contributing to RAKCHA

Thanks for your interest in RAKCHA! This is a **polyglot monorepo of four
independent apps** (they don't share a runtime API — see the
[README](README.md) and [architecture docs](docs/architecture.md)). Pick the app
you want to work on; each has its own toolchain.

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

---

## Prerequisites by app

| App | Path | Toolchain |
|---|---|---|
| Desktop | `apps/desktop` | **JDK 21** + **Maven** |
| Web | `apps/web` | **PHP 8.2+** + **Composer 2** (no Node — Encore was removed) |
| Mobile | `apps/mobile` | **Flutter / Dart** SDK |
| Firebase functions | `apps/mobile/firebase/functions` | **Node 20+** + npm |

A [`Taskfile.yml`](Taskfile.yml) wraps the common commands (`task web:test`,
`task desktop:run`, etc.) if you have [Task](https://taskfile.dev) installed.

## Fork, clone, branch

```bash
git clone https://github.com/<you>/rakcha.git
cd rakcha
git remote add upstream https://github.com/aliammari1/rakcha.git
git checkout -b feat/your-change
```

Branch prefixes: `feat/`, `fix/`, `docs/`, `refactor/`, `test/`, `chore/`, `ci/`.

## Build, run & test per app

### Desktop (JavaFX 21 + Maven)

```bash
cd apps/desktop
mvn clean compile
mvn javafx:run                 # launches com.esprit.MainApp
mvn verify                     # JUnit5 + TestFX (headless Monocle) + JaCoCo
```

### Web (Symfony 6.4 / Twig)

```bash
cd apps/web
composer install
cp .env.example .env           # default DATABASE_URL is SQLite
php bin/console doctrine:migrations:migrate
symfony server:start           # http://localhost:8000

composer test                  # PHPUnit
composer phpstan               # PHPStan + phpstan-symfony (baseline committed)
composer cs-check              # php-cs-fixer dry-run (@Symfony ruleset)
composer cs-fix                # apply fixes
```

There is **no Node build** for the web app — the dead Symfony Encore/JS was
removed and front-end assets load from a CDN.

### Mobile (FlutterFlow-exported Flutter)

```bash
cd apps/mobile
flutter pub get
flutter run
flutter analyze                # scoped via analysis_options.yaml
flutter test --coverage        # scoped to hand-written code (generated code excluded)
```

The bulk of `apps/mobile/lib` is **generated by FlutterFlow** — keep PRs focused
on hand-written code (e.g. `lib/concierge/`) and don't reformat generated files.

### Firebase functions + AI concierge

```bash
cd apps/mobile/firebase/functions
npm install
npm run lint                   # ESLint 9 (flat config)
npm test                       # Vitest
```

## CI you must pass

Every PR runs the matching workflow in [`.github/workflows`](.github/workflows):

- `ci-desktop.yml` — Maven verify + JaCoCo
- `ci-web.yml` — setup-php 8.2/8.3/8.4 → `php -l` → PHPStan → php-cs-fixer (cs2pr) → PHPUnit → Codecov
- `ci-mobile.yml` — `flutter analyze` + `flutter test` (hand-written scope)
- `codeql.yml` — CodeQL for **java-kotlin** and **javascript** (PHP has no CodeQL support → covered by PHPStan)
- `trivy.yml` — image/lockfile scan

CI **fails on error** — no warnings are swallowed. Run the relevant commands
above locally before pushing.

## Commits & PRs

- Follow [Conventional Commits](https://www.conventionalcommits.org/):
  `feat(web): add seat selection`, `fix(desktop): handle null cinema`,
  `docs: update architecture`. Scopes: `desktop`, `web`, `mobile`, `functions`,
  `docs`, `ci`.
- Keep commits focused; don't mix formatting with behavior changes.
- Fill out the PR template; link the issue you're closing.
- For larger features, open an issue first so we can agree on the approach.
